# 与黑格尔夜谈 · A Night with Hegel

> 一场关于辩证法、历史与自由的深夜对话。单文件网页小游戏，手机/桌面都能玩。

一八三一年的柏林，凌晨三点。你推开一间书房的门。桌上蜡烛快烧尽了，一个穿旧外套的老人正在写字，没有抬头。

## 玩什么

六章对话 + 两道动手题，约 10 分钟：

| 章节 | 机制 | 讲清什么 |
|---|---|---|
| 序 · 门 | 三种姿态的选择 | 你带着什么进哲学 |
| 一 · 有与无 | 排序题：有 → 无 → 变 | 正反合不是一个流程，是一个动作的三个瞬间 |
| 二 · 扬弃 | 三选一（两个是常见误解） | 否定 + 保存 + 提高 |
| 三 · 承认 | 情景抉择 | 主奴辩证法：主人依赖承认，奴隶在劳动里认出自己 |
| 四 · 理性的狡黠 | 拿破仑之问 | 历史不奖励赢家，历史利用他们 |
| 五 · 绝对精神 | 排序题：艺术 → 宗教 → 哲学 | 真理从形象到概念 |

- 答"错"不惩罚：黑格尔会顺着你的答案把话顶回来，而不是弹一个红叉。
- 11 张**概念卡**随时可翻：中德原名 + 一句白话 + 一个当代生活例子。
- 理解度决定三档结局，值得重玩一遍走另一条线。

## 跑起来

纯静态，零依赖：直接用浏览器打开 `index.html` 即可，或本地起个服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 改它

全部代码在 `index.html` 里（约 40KB，无外部资源）。剧本在 `NODES` 对象里：

```js
myNode: {who:'hegel', text:'……', choices:[
  {t:'你的回答', next:'下一个节点', insight:6, card:'yangqi'}
]}
```

概念卡在 `CARDS` 里加一条就多一张。

## 声明

本作是对黑格尔思想的**通俗演绎**，为便于理解做了大量简化与戏剧化处理，不等同于原著论证。想认真读，从《精神现象学》的"主奴"一节和《历史哲学讲演录》的"理性的狡黠"入手。
